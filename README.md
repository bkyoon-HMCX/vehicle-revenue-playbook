# 투루카 차량 매출 의사결정 플레이북

투루카 차량별 매출 관련 의사결정 기준을 부서별(Growth, Ops, Fleet)로 정리한 정적 웹페이지입니다. 단일 HTML 파일(`index.html`)로 되어 있고 빌드 과정은 없습니다.

## 게시 주소

https://bkyoon-hmcx.github.io/vehicle-revenue-playbook/

## 링크 갱신 방법

- 각 부서 담당자는 링크 시트의 자기 부서 행의 F열("링크")에 URL을 붙여넣으면 페이지에 바로 반영됩니다. 커밋이나 푸시는 필요 없습니다.
- 페이지의 "필요한 데이터" 표에서 "입력 ↗"를 누르면 시트의 해당 칸이 열립니다. 상단의 "링크 시트 열기 ↗"로 시트 전체를 열 수 있습니다.
- 페이지 자체(문구, 레이아웃)를 고치려면 저장소 담당자(BK)에게 요청하세요.
